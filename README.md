# Python Practice and Algorithm Learning Repository

This workspace contains a set of Python exercises, number-theory problems, string/logic challenges, and learning notes focused on algorithmic thinking and Python fundamentals.

## Included files

- `lesson_01_functions.py` — core function exercises and examples
- `session_01_logic.py` — logic and flow-control practice
- `strings_logic.py` — string-based challenges
- `reverse_palindrome.py` — palindrome and reverse logic
- `armstrong_tver.py`, `happy_numbers.py`, `kaprekar_numbers.py`, `disarium_numbers.py`, `strong_numbers.py` — number theory and problem-solving scripts
- `STUDY_LOG.md`, `PROGRESS.md`, and `DICTIONARY.md` — studies, progress, and terminology notes

## Run a script

From the project root:

```bash
python lesson_01_functions.py
```

Or run any other script similarly:

```bash
python armstrong_tver.py
```

## Notes

- This repo is intended for learning and incremental practice.
- Results and progress are tracked in the Markdown files in the project root.
- A virtual environment can be created if needed for future packages or tooling.
